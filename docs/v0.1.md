## 2. 核心原理与实现

### 计算图与链式法则

- `Variable` 保存 `data`、`grad` 和 `creator`。其中 `creator` 指向生成这个变量的函数，使反向传播能够追溯计算来源。
- `Function.__call__()` 执行前向计算，创建输出 `Variable`，并建立输出与函数的关联；函数也保存本次计算所需的输入、输出。
- `Function.backward(gy)` 根据当前函数的局部导数将输出梯度 `gy` 转换为输入梯度。`Variable.backward()` 从最终输出出发，沿 `creator` 逆序调用这些局部求导操作。
- `step06.py` 和 `step07.py` 展示手动及递归反向传播；`step08.py` 使用显式列表与循环替代递归；`step09.py` 自动初始化输出梯度，并提供 `square()`、`exp()` 等调用函数。

例如：

\[
y = \operatorname{square}(\operatorname{exp}(\operatorname{square}(x))) = e^{2x^2}
\]

由链式法则：

\[
\frac{dy}{dx} = 4x e^{2x^2}
\]

取 \(x=0.5\)，解析梯度约为 `3.2974425414`，与当前自动微分结果一致。

### 数值微分的作用

`step04.py` 使用中心差分近似：

\[
f'(x) \approx \frac{f(x+\varepsilon)-f(x-\varepsilon)}{2\varepsilon}
\]

数值微分不需要实现反向传播，适合作为**独立的梯度正确性检查**；但每次求导需要额外的函数计算，并存在截断误差和浮点误差，因此不适合作为实际神经网络训练中大规模求梯度的主要方法。

## 4. 当前边界与下一步

- 当前 `Function` 面向单输入、单输出；主要支持简单链式计算图，尚不支持通用分支图和梯度累积。
- **不要复用同一个 `Function` 对象处理连续计算**：现有 `__call__()` 会覆盖实例上的 `input`、`output`。应使用 `square(x)`、`exp(x)` 这种每次新建实例的包装函数。
- 暂不支持加减乘除运算符重载、张量广播、复杂反向传播顺序管理。这些留到 v0.2 或后续版本。
- 代码为教学演进示例，暂不要求 `learndl` 正式 Python 包结构。
