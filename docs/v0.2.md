# LearnDL v0.2 — 复杂计算图与基础运算

> 参考：《深度学习入门2：自制框架》步骤 11–24  
> 状态：**Code Freeze 候选**；功能与测试验收通过，Git 提交与 `v0.2` Tag 由维护者执行。  
> 项目名：LearnDL；本阶段 Python 包名：`dezero`

## 1. 本版解决了什么问题

v0.1 解决**单链复合函数求导**。v0.2 解决**共享变量与分支图的正确反向传播**，进一步将加减乘除、负号、常数幂封装为接近普通 Python 的数学表达式。学习脚本保留每一步的演进过程；正式可复用实现在 `dezero/core_simple.py`。

## 2. 关键原理（能解释而不只是能运行）

| 主题 | 实现位置 | 必须掌握的要点 |
| --- | --- | --- |
| 多输入、多输出 | Step11–13、`Function.__call__()` | 将每个输出的梯度交给 `Function.backward()`，并将返回的每个输入梯度分发到相应 `Variable`。 |
| 梯度累积 | Step14、`Variable.backward()` | `y=x+x` 的梯度是 2；同一个变量可能从多条边收到贡献，不能覆盖先前的梯度。 |
| 复杂分支图 | Step15（理论）、Step16 | `generation` 决定逆向处理顺序；`seen_set` 防止同一函数重复入队。先汇总梯度，再运行一次上游反传。 |
| 内存与弱引用 | Step17–18 | `Function` 强引用输入、弱引用输出；反向传播时失效的多输出分支以零梯度处理。默认不保留中间梯度。 |
| `no_grad()` | Step18 | 在不需要梯度的前向计算中跳过图构建；上下文退出时恢复原配置，异常也可恢复。 |
| 运算符重载 | Step19–22 | `+`、`-`、`*`、`/`、`**`、一元负号和反向操作把自然表达式映射为小型算子；`as_array()` / `as_variable()` 接收 Python 标量。 |
| 包入口 | Step23、`dezero/__init__.py` | 导入 `dezero` 时暴露 `Variable`、`Function` 等，并调用 `setup_variable()` 完成运算符绑定。 |
| 复杂函数 | Step24 | Sphere、Matyas、Goldstein–Price 展示复合表达式由基础算子自动求导，可通过解析式或中心差分验算。 |

## 3. 两个必须会手算的例子

**分支图：** 对 `x=2`，令 `a=x*x`，`z=a*a+a*a = 2x⁴`。因此 `z=32`，`dz/dx=8x³=64`。验证了共享中间变量梯度的正确汇总。

**Matyas 函数：** `f(x,y)=0.26(x²+y²)-0.48xy`，因此

- `∂f/∂x = 0.52x - 0.48y`
- `∂f/∂y = 0.52y - 0.48x`

在 `x=1, y=2` 时，前向结果 `0.34`，梯度分别为 `-0.44`、`0.56`。

## 5. 明确不做（留给后续版本）

- v0.3：反向传播本身构建计算图、`create_graph`、二阶及更高阶导数。
- v0.4：广播梯度归约、`sum_to`、reshape/transpose、矩阵乘法梯度。
- 不承诺与 PyTorch API 对齐，不增加 GPU、生产级内存管理或复杂框架配置。

**小结：** v0.2 从“沿一条链反传”走到了“能正确遍历复杂计算图并用自然数学表达式计算梯度”。下一个主要学习目标是高阶自动微分，而非继续扩充当前算子数量。
