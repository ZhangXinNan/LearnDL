# LearnDL v0.6 封版审查与验收记录（候选）

> 日期：2026-10-28。范围：教材 Step47–51，结合 Step01–46 回归。

## 学习目标

完成从 `Variable/Function`、反向传播、张量算子、`Layer`、SGD 到 Softmax Cross Entropy、mini-batch、分类训练及评估的完整闭环。

## 审查修复

1. `steps/step50.py`、`steps/step51.py` 的评估循环必须使用 `test_loader` 而不是 `train_loader`；计算 test loss/accuracy 时分母必须是 `len(test_set)`。
2. `dezero/functions.py` 中 SoftmaxCrossEntropy 的目标标签在反向阶段先 `ravel()`，避免 `(N, 1)` 标签造成 `(N, N, C)` 形状的错误梯度；one-hot 数据类型与 logits 对齐。
3. 记录 `Pillow` 依赖；补齐 `tests/test_v05.py`、`tests/test_v06.py` 离线回归。
4. 更新 README 和步骤入口，使用 `python -m steps.step50` 而不是依赖环境变量的脚本路径。

## 最小复现命令

```bash
python -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s tests -v
OPENBLAS_NUM_THREADS=1 python -m steps.step50
OPENBLAS_NUM_THREADS=1 python -m steps.step51
```

`step51.py` 默认 `hidden_size=1000`、`batch_size=10`、`max_epoch=5`；仅用于原书复现。在资源有限的 CPU 上可先缩小隐藏层和 epoch 验证端到端学习能力，并记录实际使用配置。正式封版以真实 MNIST 独立测试集结果为准。
